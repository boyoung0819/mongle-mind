# 몽글마음 (Mongle Mind)

스트레스와 불안으로 지친 마음이 잠시 쉬어 갈 수 있도록 돕는 2.5D 분위기의 웹 힐링 육성 게임 프로토타입입니다.

## 실행 방법
1. Python 3.10 이상을 설치합니다.
2. 터미널에서 프로젝트 폴더로 이동합니다.
3. `pip install -r requirements.txt`
4. `streamlit run main.py`

## 현재 포함된 기능
- 2.5D 느낌의 마을 화면과 전신 캐릭터
- 방향키 또는 WASD 이동
- E 키 또는 화면 버튼으로 가까운 대상과 상호작용
- 꽃 돌보기, 꽃 수집, 코인 및 경험치 보상
- 캐릭터 의상 선택
- 기분 색깔 기록과 선택형 호흡 활동
- 브라우저에 게임 진행 상황 자동 저장(localStorage)

## 알아둘 점
- 이 버전은 첫 번째 플레이 가능한 프로토타입입니다. 저장은 현재 사용 중인 브라우저에만 저장됩니다.
- 다른 기기에서도 이어하기 위한 계정 기반 영구 저장은 추후 Supabase를 연결해야 합니다.
- 이 게임은 휴식과 자기 성찰을 돕기 위한 경험이며 의료적 치료나 진단을 대신하지 않습니다.
